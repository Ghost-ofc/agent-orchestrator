# Identidad visual

El logo representa un nodo coordinador conectado a tres agentes dentro de una «A» geométrica. Los acentos azules y turquesa acompañan la interfaz oscura del panel.

- Archivo principal: [logo.png](../plugins/agent-orchestrator/web/logo.png).
- Formato: PNG RGBA con fondo transparente.
- Uso: README, cabecera del panel y favicon. El nombre del producto se mantiene como texto accesible junto al símbolo.
- Generación: herramienta integrada `imagegen`; el archivo generado se incorporó al repositorio sin modificarlo.
